# Parity with neuroglancer

Each row is a part of neuroglancer's TypeScript (`../neuroglancer/src`) and
where it stands in Rust. "Done" means ported **and** checked against
neuroglancer's own behavior, not just written.

How things are checked, strongest first:
- **Run neuroglancer's code.** `scripts/golden/ng_register.mjs` lets node import
  neuroglancer's TypeScript sources directly (compiled with its own tsconfig
  options); golden scripts drive the real classes and record what they do.
- **Neuroglancer's libraries.** Where a source can't run outside the browser,
  the golden uses the same libraries (nifti-reader-js, gl-matrix) with the
  logic copied verbatim and marked as such.
- **Image comparison** between backends and against CPU expectations.

Status: ✅ done · 🟡 partial · 🧪 stand-in, to be replaced · ⬜ not started
